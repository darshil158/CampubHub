# Campus Hub 🎓

> The all-in-one college community platform for students.

Campus Hub is a modern, enterprise-grade university community application built with React, Vite, Tailwind CSS v4, Framer Motion, and Supabase.

---

## 🚀 Features

- **🛍️ Marketplace**: Buy and sell textbooks, electronics, dorm essentials, and college gear within your campus.
- **💼 Campus Jobs**: Discover and post part-time roles, research assistantships, on-campus employment, and student freelance gigs.
- **🏠 Roommates & Housing**: Find compatible student roommates, open rooms, subleases, and off-campus housing.
- **🎓 Peer Tutoring**: Connect with student mentors for coursework guidance and exam preparation.
- **⚡ Skill Exchange**: Trade talents including coding, languages, design, and music.
- **📝 Study Notes**: Share and access crowdsourced lecture summaries and study guides.
- **👤 Profile & Dashboard**: Manage your active listings, job postings, housing offers, and settings.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS v4, Framer Motion, Lucide React
- **Backend / Database**: Supabase (PostgreSQL, Row Level Security, Auth)
- **Deployment**: Vercel / Render

## 🏁 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/darshil158/CampubHub.git
cd CampubHub
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

### 4. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
